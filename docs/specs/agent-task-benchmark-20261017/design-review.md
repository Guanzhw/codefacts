# Task and rubric review

The first frozen suite was reviewed against its task prompts by an independent reviewer who did not see answers, grades, arms, timing or usage.

Three all-components-required criteria exceeded the explicit question scope:

- globset-01 allowed a test or documented example but C4 required the specific `set_works` test.
- globset-02 C4 required enumerating the ordinary, strategic and GlobSet test matchers.
- ghcli-02 C4 required flag parsing, authentication exemption and execution-error wrapping beyond the requested examples and missing-argument/shell failures.

The v1 pilot was stopped after 16 completed attempts. A seventeenth attempt had already started when the controller stopped; its raw events are retained and exact usage remains unknown. These observations are preparation evidence and are excluded from the reviewed baseline. The original frozen inputs and grades remain intact locally.

`source-investigation-v2` explicitly requests these details. It also makes implementation-trace components explicit in the router questions. The four criteria, critical gates and all source anchors are unchanged. The reviewer confirmed the other task requirements align, that concise answers within 300 words are feasible, and that the added topics do not supply the implementation answers. The final wording asks about both regular and shell aliases, matching C4.

The new baseline uses a fresh freeze, four readiness canaries and the complete 96-slot schedule. It does not combine pilot attempts with the new task version. All answers and grades retain their original bytes; portable publication removes only the local evidence-path object.
