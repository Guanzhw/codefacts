# Repair design

Type-reference extraction should consume one consistent Tree-sitter capture
contract per match. Tests must distinguish declaration identifiers from real
uses and check ownership at exact source positions. Fix demonstrated query or
extractor gaps at their owning boundary; keep call resolution separate.
An extraction-version increment invalidates old incomplete facts even when
file hashes are unchanged. Its one-time re-extraction cost must be visible.

`explore` already has typed Freshness values. Render omission counts only
when freshness is partial, using actual failure/too-large categories rather
than the combined skipped counter that includes normal unchanged files.
Retain the existing response-budget fitter and source verification.

Upgrade measurements use new private database copies, actual stdio requests,
closed-file allocation data and immutable read-only inspection of originals.
Published 0.2.0 schema migration and repaired-candidate extraction refresh have
different expected transitions and separate receipts.

The profile study has two stages. Forced inventory/call canaries establish
current availability. Natural-choice tasks then measure observed adoption and
task outcomes on a fixed candidate. Successful current canaries do not fill
historical catalog gaps. Independent graders receive anonymous answers and
frozen source/rubrics before arm or efficiency data.

Native agents own disjoint source files. DSH Flash workers own separate
evidence directories, reproduce actual runtime behavior and provide advisory
findings. The main agent checks source claims, reviews integrated changes and
retains final release judgment.
