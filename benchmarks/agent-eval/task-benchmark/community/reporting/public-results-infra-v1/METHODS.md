# Public result arithmetic package v1

Authoring status: **DRAFT / UNEXECUTED**. Syntax, synthetic and real full288 integration checks have not been run for this draft; acceptance is recorded separately when actually performed.

This package retains all 288 planned model/task/arm cells, 24 source tasks and four model configurations. It reproduces the public numerical projection of one already accepted CodeFacts 0.2.2 / CodeGraph 1.6.2 / ordinary-tools report. Obtain the manifest SHA-256 separately from the accepted delivery record, then run:

```sh
node verify.mjs --manifest manifest.json --sha256 <independently-recorded-manifest-sha256>
```

Only Node builtins and files in this directory are required. The verifier writes no files, does not use the network, and checks the declared file inventory and raw hashes before loading the bundled producer arithmetic. `expected.json` is a whitelist projection of the accepted internal report; it is not generated by the public recomputation. The verifier recomputes all listed statistics from `data.json` and compares the complete projected result, including every retained pair.

`data.json` retains model, cohort, source-task, language, split, arm and terminal/grade identity; all 17 producer resources; exact token measurements and separate lower bounds; eight nullable Context localization values and the non-null declaration-metrics marker; nullable SWE boolean; native call/adoption counts; opaque error categories; signed premodel failure history; and physical allocation inventories. Tasks retain dataset plus instance identity, repository and base commit. The same issue ID may occur in different cohorts with different base commits.

Context is adapted reference localization agreement. Valid-declaration counts and complete-eight-metric counts are separate. The owning summary emits a SWE boolean only with completed grading; failed official grading produces resolved=null. Model attempt failure is independent: task-failed with completed official grading can retain resolved=true. Missing quality remains unknown in fixed-denominator bounds. Pilot and confirmation remain separate; only Context confirmation carries the historically observed replication label.

Pairs compare the same task and model, treatment minus ordinary, without filtering by correctness or native adoption. CLI-5698 remains in primary results and is uniformly excluded only in the Context sensitivity. Language panels and equal-model macros use the producer formulas. Token/time comparisons stay within model; there is no pooled cross-tokenizer efficiency score. Exact null, evidenced zero and usage lower bounds remain distinct.

Each timing field is aggregated separately. Preparation includes source preparation, native cold indexing and SWE sandbox start. DSH includes model-turn time. Slot wall includes nested phases and some inline grading; external audits may be outside it. These overlapping clocks are not summed. A provider/task failure may have null exact usage and a positive known usage lower bound. A zero-usage failed stream chunk does not establish zero usage for the whole session. A fresh private index does not establish an OS cache flush or isolated hardware timing. This experiment did not isolate the effect of three versus seven/one tool entry points.

Logical index bytes are setup file lengths. Physical bytes are a later separately measured Windows FileStandardInfo allocation snapshot; timestamps and actual receipt coverage are retained. Fixed physical group denominators include all 192 planned native cells. The expected successful count is 192 minus the accepted signed infrastructure count, not a hard-coded result. Missing receipt coverage remains unknown. Receipt-wide buckets retain the receipt's actual scope; they do not manufacture measurement of uncovered cells.

All evidenced measured file identities are mapped through one package-wide opaque map, retaining hardlink equality within and across successful and archived failure inventories. Unmeasured or failed-to-measure inventories retain their status and unknown allocation; incidental partial/error file records are outside the public numerical projection. Successful-formal, failure-retained and all-retained buckets deduplicate separately. Failure allocation never becomes a successful cold-index sample. Failed slot history retains canonical overlap and archived-only costs without adding them to model clocks.

The public package contains no raw receipt, patch path, private source/gold/answer/session/trace, arbitrary original error text or local absolute evidence path. Error categories preserve equality and counts within this package; category labels carry no causal diagnosis. Original metadata/summary/report/ledger hashes identify private accepted sources. Public projection hashes identify different bytes. No closure or approval is minted or re-signed by this package.

Arithmetic agreement verifies reproducibility of published statistics. Official grading correctness, frozen source/runtime provenance and operational closure remain facts established by the existing acceptance process. The package does not reconstruct those private source audits or rerun models or official scoring. Repository/base identities support project/task regrouping from the same observations; additional regrouping is descriptive and does not add independent tasks.

The bundled `producer-core.mjs` is derived from the independently reviewed aggregate source version `2.0.0-infra`, raw SHA-256 `0dd4b180a9e0016a95e3e8548f0db548ef1d6c0fd7c0654a469744a7f7307ae2`, framework revision `ec1c7f7d788db8244388e200f5849de3b1564b21`. Derivation `aggregate-core-v1` copies the contiguous ARMS-through-panel arithmetic, the macro helper, and the equalModelMacro expression verbatim; it adds a builtin crypto import and exports/wrappers, and omits IO, CLI, private closure validation and receipt ingestion. `statistics.mjs` adapts those pure functions to public rows and reproduces the producer's physical deduplication arithmetic. Every bundled source file has its own manifest hash.
